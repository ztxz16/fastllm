## GGUF 输出与矩阵分块调优（2026-11-15）

在上一轮 MMQ 调度基础上继续优化，直接修改 master，未改变权重、部署参数或依赖。GGUF 权重保持原始压缩块驻留，没有缓存整份展开的 BF16 模型。大 token 图像推理以矩阵计算为主，GGUF 的逐块缩放与解量化有额外成本，不能仅凭位宽推断它会比 BF16 / FP8 快。

### 实现与边界

- 缓存后的 513..1024-token Q4_K gate/up 使用原 MMQ 的 Tensor Core 内积，直接将寄存器中的 FP32 累加结果写为 BF16 / FP32，去掉约 60 MiB FP32 暂存和其后转换、复制，以及由此产生的第二轮分块；此路径 Q8 临时区最多 4.5 MiB。
- 仅该 SM120 gate/up 路径显式使用 FMA 做缩放累加。共享 MMQ 模板保留默认的原累加顺序和 FP32 输出；H3 与 LLM 调用不启用该选项，项目编译仍保持 `--fmad=false`。
- SM120 的 513..1024-token、4096→4096 回退 GEMM 使用 4096 行解量化分块。其他尺寸沿用 2048 行上限；新路径的解量化缓冲不超过 32 MiB。12,288→4096 降维层缩到 1024 行的实验在生产 4 MiB cuBLAS 工作区下反而更慢，已撤回。
- 去噪阶段的大 token Q/K/V 直接写入最终输出列区间，保留各自 GGUF 位宽，省去中间张量及三次二维复制。前缀构建仍用原调度，以保持条件缓存一致。
- 实验比较了 48/64/96/128 MMQ tile、直接输出、显式 FMA、cuBLAS/Lt 多种分块和归约策略。4096-token 的强制 MMQ 仍更慢，最终继续选 cuBLAS 回退；没有合入全局 fast-math、额外运行开关或未胜出的实验分支。

## GGUF MMQ 形状与前缀调度（2026-11-15）

复用 MiniMax H3 Image 的 GGUF reader、Q8 激活打包和 INT8 Tensor Core MMQ，不改权重、不持久化展开后的 BF16 权重。直接在 master 接入，没有新增 CLI / API 参数或环境变量，仍为纯 C++ / CUDA。

- SM120 上，Q4_K 的 4096→24576 合并 gate/up 投影在**已有前缀缓存的去噪阶段**允许 513..1024 token 走 MMQ。512² 编辑的 1024-token 主干因此使用该路径。
- 前缀构建保留原 8..512-token 调度。实验中，把双图首步的 721-token 联合计算也改成 MMQ 会使 40 步 latent 相对 L2 从 5.1181% 增至 7.7811%；最终实现撤回此扩展，4/40 步多图的全部快照和 PNG 恢复为此前逐字节一致。

## BF16 进一步算子优化（2026-11-15）

继续在同一 master 工作区、物理 GPU 6 上优化，生产路径仍为纯 C++ / CUDA / cuBLAS / CUTLASS。没有新增环境变量、命令行选项或依赖，共用运行时的默认数值策略不变，BF16 split-K 仅由 Qwen 主动启用。

- QKV norm/RoPE 改为每半个 warp 处理一个 head，采用 128-bit 读写，旋转的相邻元素保存在寄存器；保留两次 BF16 归一化舍入。归约顺序改变，因此通过相对 L2 验证。

- MLP down 等符合现有调优条件的大尺寸降维投影，额外允许 BF16 split-K 部分和，由已有的两候选调优选择。块内仍为 FP32 累加；其他模型默认禁用，FP32 路径不启用。微基准中降维 GEMM 约快 7%～11%，相对旧 FP32 归约的 L2 约 0.264%。

## BF16 推理优化与 SGLang 复测（2026-11-15）

### 改动

- 根据当前空闲显存和请求形状，自动选择权重常驻/完整 KV 缓冲或阶段卸载/前缀缓存；有界临时张量池在请求结束归还空闲页。取消或异常释放权重。

### 波形核对

Nsight 的独立诊断可执行文件从当前源码生成，不在生产代码加入 NVTX。每种模式预热后采集 40 步，算子统计使用后 39 步；profiling 输出与无 profiler 的 4 次请求 PNG 逐字节一致。

| DiT 每步 GPU 耗时 | 文生图：前 → 后 | 编辑：前 → 后 |

| QK norm/RoPE，优化后含 V 写入 | 8.373 → 6.520 ms | 1.673 → 1.200 ms |
| RoPE H2D | 4.921 → 0 ms | 1.294 → 0 ms |
| KV 拼接 D2D | 2.032 → 0 ms | 0.906 → 0 ms |
| SiLU + 乘法 | 14.823 → 7.698 ms | 2.713 → 0.961 ms |
| Gated residual | 5.424 → 3.365 ms | 1.372 → 0.664 ms |
